Explicación

Nota sobre la API

La clave pública rc_live_demo devuelve un único país de muestra y rechaza peticiones desde orígenes no autorizados. Por eso la aplicación intenta primero la API oficial y, si no está disponible, muestra un catálogo de respaldo generado desde el dataset oficial de REST Countries. El código de la petición con fetch() y onMounted() se conserva y se documenta en este PDF.
